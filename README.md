# سهم ⚡ — لعبة السوق الحقيقية

> «العالم الحقيقي هو الملعب، وأنت تتداول بمال وهمي، وتنافس أصدقاءك على من يتوقّع السوق بدقة أكبر.»

لعبة تعليمية ترفيهية تعمل كـ Mini App داخل بوت تيليجرام — أسعار سوق **حقيقية 100%** + مال وهمي + مجانية.
التوثيق الكامل للتصميم في [GAME_DESIGN.md](GAME_DESIGN.md).

## ما تم بناؤه (المرحلة 0 + 1 من خارطة الطريق)

| الجهازة | الحالة |
|---|---|
| 🤖 بوت تيليجرام (aiogram 3 + webhook) | ✅ /start، /markets، /predict، /portfolio، /leaderboard، /arcade |
| 📈 أسعار حيّة (Yahoo Finance) | ✅ تداول 🇸🇦 + الأمريكي 🇺🇸 + كريبتو 🌐 — تحديث كل ساعة، طلب واحد يخدم الجميع |
| ⚡ وضع الأركيد | ✅ نافذة تاريخية حقيقية عشوائية، يوم تداول = 4 ثوان، شراء/بيع بعمولة 0.1% |
| 🎯 العائد الزائد | ✅ التقييم مقارنة بمرجع السوق — الصعود العام لا يكفي للفوز |
| 🚫 مضاد الغش | ✅ الشموع تُسلّم خطوة-بخطوة بتوقيت الخادم + نافذة عشوائية |
| 🎮 Mini App | ✅ واجهة عربية RTL + رسوم شموع (lightweight-charts) |
| 🔐 المصادقة | ✅ تحقق HMAC من initData بتيليجرام + توكن موقّع |

## البنية

```
app/
├── main.py           # FastAPI: webhook البوت + REST API + الجدولة
├── bot.py            # أوامر ولوحات aiogram
├── services.py       # المستخدمون، المحفظة، التوقعات، محرك الأركيد
├── market_data.py    # طبقة البيانات: جلب + كاش + تاريخ
├── constants.py      # قوائم الأسهم والثوابت
├── config.py         # الإعدادات من البيئة
└── db.py             # SQLite (SCHEMA وفق القسم 6 من الخطة)
web/                  # التطبيق المصغّر (Vanilla JS) → يُستضاف على Cloudflare Pages
```

## التشغيل محليًا

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
export BOT_TOKEN="توكن البوت من BotFather"
python seed_data.py          # تخزين التاريخ الحقيقي (مرة واحدة)
uvicorn app.main:app --port 8080
# الواجهة: http://localhost:8080/app/
```

## النشر

- **الخادم:** Render Web Service (runtime: Python) — يقرأ `BOT_TOKEN` من البيئة، ويضبط `webhook` تلقائيًا من `RENDER_EXTERNAL_URL`.
- **الواجهة:** Cloudflare Pages من مجلد `web/` (لمطابقة الأمان أنشئ `WEBAPP_URL`، وخلاف ذلك تُخدم الواجهة من الخادم نفسه على `/app/`).

> ⚠️ **ملاحظات مهمة:**
> - خطة Render المجانية: الخدمة تنام بعد خم عشر دقائق خمول (مستخدم أول يوقظها). SQLite على الخطة المجانية مؤقت — الانتقال ليسبعا ل Postgres عند النمو (الجداول جاهزة للنقل).
> - **ممنوع قانونيًا:** لا سحب ولا تحويل لمال حقيقي — اللعبة نقاط وهمية فقط (القسم 14 من الخطة).
